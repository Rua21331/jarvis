 ## Jarvis AI Assistant

Bu proje, tarafımdan yeniden düzenlenerek Microsoft Windows sistemleriyle daha uyumlu hale getirilmiş bir AI masaüstü asistanıdır.

Jarvis;

* sesli komutları dinleyebilir,
* bilgisayarı kontrol edebilir,
* uygulama açabilir,
* sesli yanıt verebilir,
* masaüstü görevlerini otomatikleştirebilir.

Proje aktif olarak geliştirilmektedir ve yeni özellikler düzenli olarak eklenmektedir.

Özellikler

* Voice command system
* Desktop automation
* Speech response system
* Application control
* File management features
* Web research support
* Extended Windows compatibility

## Yönetici Modu

Bazı gelişmiş sistem özelliklerinin tam kapasite çalışabilmesi için:

```bash
Jarvis yönetici modunu başlat
```

komutunun kullanılması gerekmektedir.

Bu mod;

* dosya düzenleme,
* veri aktarma,
* araştırma işlemleri,
* gelişmiş sistem kontrolü

gibi ek işlevleri aktif hale getirir.
